# Quantacus Jewellery Growth Strategy & SQL Analytics Case Study

A comprehensive end-to-end data analytics and performance marketing growth case study for **Quantacus Jewellery**. This project demonstrates how leveraging SQL analytical pipelines, feed hygiene, statistical thresholding, and hero SKU pruning scales Return on Ad Spend (ROAS) from **3.4 to 5.0+**.

---

## 📊 Executive Summary

* **Objective:** Drive profitable growth and improve campaign performance across performance marketing channels for Quantacus Jewellery.
* **Core KPI Targeted:** Target ROAS expansion from **3.4x to 5.0x+**.
* **Key Lever:** SQL-driven audience/product segmentation, product feed hygiene optimization, and statistical thresholding to eliminate ad spend waste on low-converting SKUs.
